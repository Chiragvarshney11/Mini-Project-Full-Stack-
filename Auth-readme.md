# Authentication UI

This branch contains the **Authentication frontend UI** for the Learning Management System (LMS).

## Scope

### Authentication
- Landing Page
- Login
- Registration
- Forgot Password
- Form Validation States
- Authentication-related UI Components

## Technology

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons

This branch is **frontend/UI only** and uses mock/sample data where required. Backend authentication, APIs, database connectivity, and server-side functionality are outside the current project scope.
